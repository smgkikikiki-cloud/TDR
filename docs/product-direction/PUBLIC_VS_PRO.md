# TDR: เว็บสาธารณะ vs TDR Pro — รายละเอียดทิศทาง (16 ต.ค. 2569)

สถานะ: บันทึกการตัดสินใจของกี้ (ดู `docs/MERGE_DECISIONS.md` หัวข้อ "ทิศทางผลิตภัณฑ์" P1–P2) · **เอกสารล้วน** ไม่ใช่ใบสั่งงาน · `portfolio.plan.json` ยัง `execution.enabled=false`, `task_queue=[]` · ไม่รวมราคา การชำระเงิน หรือเงื่อนไขทางการค้า (G0-C03 และเกตเรื่องราคา/ที่นั่งของ roadmap ยังเปิด)

## 1. บทบาท
- **เว็บ TDR สาธารณะ:** ต้อนรับ เทียบรถ ดู snapshot ตลาด โฆษณาสินค้า ลงข่าว → traffic และ SEO
- **TDR Pro:** หน้าต่างแยก (workbench) สำหรับสมาชิกที่จ่ายเงิน ลูกค้าหลักคือคนทำงาน/ขายรถในดีลเลอร์ (Layer 1–2)
- **TDR Enterprise:** ติดต่อทีมงาน ไม่แสดงราคา · แนวคิด Layer 3 ของ roadmap (Dealership Toolkit) · **การจับคู่ชื่อกับ roadmap ยังไม่ผูก** ห้ามเปลี่ยนชื่อบนเว็บจนกว่ากี้ยืนยัน
- **ข้อจำกัดของ workbench:** Layer 2 เท่านั้น · ไม่ใช่ยอดขายของดีลเลอร์ · ไม่แนะนำทำเลหรือสต็อก · ไม่มี Lego builder · ข้อมูลในเดโมเป็นข้อมูลสังเคราะห์ (DEMO) ทั้งหมด

## 2. หน้า `/market` ใหม่ (ดีไซน์นิ่งแล้ว ยังไม่ implement)
ลำดับ: KPI ภาพรวม → รุ่นยอดนิยม 20 อันดับ + สัดส่วนพลังงาน + ยอดรายจังหวัด → ตัวอย่างฟีเจอร์ Pro แบบล็อก → การ์ด Pro / Enterprise + ตารางเทียบ

กติกา:
- ขอบเขตฟรีอิง `panel.json` ของแพ็กเกจ M7.0: งวดล่าสุดเท่านั้น, 20 อันดับ (ไม่มีการเทียบ), 77 จังหวัด · ประวัติและการเทียบ = Pro · CSV ดิบ = Enterprise
- **ไม่ใส่ราคา** จนกว่า G0-C03 ปิด · ใช้ "เร็วๆ นี้ / ลงทะเบียนรอ" จนกว่า TDR Pro ตัวจริงเปิด
- ตัวอย่างฟีเจอร์ที่ล็อกต้องบอกว่าเป็นตัวอย่างของสิ่งที่กำลังพัฒนา ไม่ใช่ข้อมูลจริง และข้อมูลจริงต้องไม่อยู่ใน DOM/JSON (กฎ V/C)
- ทุกจุดที่แสดงรายจังหวัด: หมายเหตุ "จังหวัดที่จด ≠ จังหวัดที่ใช้งาน" · ยอดจดทะเบียน ไม่ใช่ยอดขาย · ห้ามระบุแหล่งข้อมูลสเปก · ห้ามบอกว่าข้อมูลล้อ/ยางมาจากกรมขนส่ง
- ไม่มีส่วนข่าวบนหน้านี้ · ปุ่มหลักสีเข้มปุ่มเดียวต่อหน้าจอ · สีผ่าน token เท่านั้น
- **ไม่ redirect** (แทนเฉพาะ `/market → /intelligence/share` ในรายการ redirect R1–R4 เดิม)
- การ implement: ปรับ PR #259 (`design/market`, restyle /market แบบเดิม, ยังเป็น draft) หรือเปิด PR ใหม่ — กี้เลือก · ไม่ merge โดยไม่มีคำสั่งกี้

## 3. TDR Pro workbench (เดโมดีไซน์)
หน้าหลัก: Radar, Explorer, Arena, Pipeline, Watch, Market Book + Login/Account + mobile/dark
- **Geography:** เริ่มระดับภูมิภาค เปิดทีละภูมิภาคเพื่อดูจังหวัด · ซ่อนจังหวัดที่ตัวหารน้อย (เกณฑ์ที่ใช้ในเดโมคือ 150 คัน ซึ่งรอ Ice ยืนยัน ยังไม่ใช่กฎ)
- **Launch Curve:** เส้นยอดสะสมหลังเปิดตัว เทียบรุ่นก่อนหน้าในเซกเมนต์เดียวกัน
- **Pipeline:** รุ่นใหม่ที่จะเปิดตัว มีสถานะและแหล่งที่มา ไม่พยากรณ์ยอด · ต้องมีแหล่งข้อมูลแยก (ไม่อยู่ในแพ็กเกจ)
- **มุมมองของฉัน + จุดอ้างอิง (Ground 0):** ตั้งแบรนด์/พื้นที่ครั้งเดียว แล้วเทียบกับ ตลาดรวม / รุ่นของฉัน / พื้นที่ของฉัน และบันทึกลง Market Book พร้อมระบุว่าเทียบกับอะไร (ยังไม่ผูกกับ Radar/Explorer/Watch)

## 4. ข้อมูลที่ต้องมีก่อนสร้างจริง
- `dims/province.csv` ของแพ็กเกจไม่มีคอลัมน์ภูมิภาค → ต้องมีตารางจังหวัด→ภูมิภาคและ Ice ยืนยัน
- ราคาป้ายรายเดือนและข้อมูลรุ่นใหม่ที่จะเปิดตัว **ไม่อยู่ในแพ็กเกจ**
- สิทธิ์ของ Ice ในการนำข้อมูลเชิงอนุพันธ์/ส่งออกไปแสดงในผลิตภัณฑ์ที่ขาย ยังไม่ได้ตรวจ
