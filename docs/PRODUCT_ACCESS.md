# TDR — ชั้นการเข้าถึงและราคา

ตกลงกับเจ้าของผลิตภัณฑ์แล้ว ใช้ไฟล์นี้เป็นแหล่งอ้างอิงเดียว ห้ามเดาจากโค้ดเดิม

### การเข้าถึงหลัง login

ล็อกอินสำเร็จ = ใช้สิทธิ์ตาม tier ได้ทันที ไม่ต้องยืนยันเบอร์/กรอกโปรไฟล์ก่อน
`phone / postcode / บุคคล-องค์กร / marketing consent` เป็นข้อมูลเสริมที่กรอกเพิ่มได้
ที่ `/member/profile` ไม่ใช่เงื่อนไขเปิดใช้งาน

ยืนยันตัวตน (อีเมล + OTP เบอร์มือถือ + โปรไฟล์ครบ) บังคับเฉพาะตอน **สมัครแพ็กเกจแบบชำระเงิน**
เพราะเป็นธุรกรรมที่ตัวตนคือสาระของงานเอง

### วิธีนับ

- **เทียบสเปก 10 ครั้ง/วัน** นับตอนกดปุ่มเทียบ ไม่ใช่ตอนเลือกรถ เก็บใน cookie ฝั่ง
  server (httpOnly) รีเซ็ตรายวันเวลาไทย ตั้งใจให้เป็นรายวันไม่ใช่รวมทั้งหมด เพื่อให้
  คนกลับมาใช้ซ้ำได้ทุกวัน กันคนทั่วไปพอ ไม่ได้กันคนตั้งใจโกงซึ่งไม่คุ้มจะกัน
- **เปิด `/market` ของ anon ไม่กิน quota** หน้า public เป็น snapshot จริงของงวดล่าสุด
  เปิดซ้ำ refresh หรือถูก Next.js prefetch/RSC request ก็ต้องไม่สร้าง usage ใดๆ
- **interaction คือ boundary ของ market** การเปลี่ยน dimension / window / comparison /
  filter / drilldown เริ่มที่ `/member/market` และต้องมีบัญชี
- **market 5 ครั้ง/วัน ของ FREE** นับเมื่อเกิด analysis request ที่ดึงข้อมูลจริง
  เปิดหน้าเฉยๆ หรือ refresh ไม่นับ
- **บทวิเคราะห์ 2/เดือน** นับตอนเปิดอ่านเต็มครั้งแรกของบทความนั้น
  อ่านซ้ำบทความเดิมไม่นับเพิ่ม

## ราคา

| | ราคา | หมายเหตุ |
|---|---|---|
| Free | ฿0 | funnel |
| **Pro** (รายคน) — รายเดือน | **฿1,290/เดือน** | ไม่ผูกมัด เรียกเก็บทุกเดือน |
| **Pro** — ผูกมัด 3 เดือน | **฿990/เดือน** (รวม ฿2,970/รอบ) | เรียกเก็บเต็มก้อนล่วงหน้าทุก 3 เดือน |
| **Pro** — รายปี | **฿790/เดือน** (รวม ฿9,480/ปี) | เรียกเก็บเต็มก้อนล่วงหน้าทุกปี |
| Enterprise (TDR Enterprise package) | ปรับตามการใช้งานจริง | **ยังไม่ขึ้นเว็บ** ใช้ปุ่ม "ติดต่อเรา" เดียว ไม่มี Team แยก |

- **ยุบ ฿399 ทิ้ง** — ห่างจาก Pro เดิม (฿990) น้อยเกินกว่าจะช่วยตัดสินใจ Pro คือชั้นเสียเงินชั้นเดียว ปลดล็อกทุกอย่างเหมือนกันไม่ว่าจะสมัครแบบไหน ต่างกันแค่ระยะผูกมัด/ราคา
- Team ถูกยุบรวมเข้ากับ Enterprise เป็นบล็อกเดียว — "TDR Enterprise package" ปุ่มติดต่อเดียว ไม่แยกราคา/ที่นั่งบนเว็บ ปรับตามดีลจริงแต่ละองค์กร
- ยังไม่ติดราคา Enterprise บนเว็บ เพื่อไม่เสียอำนาจต่อรองก่อนปิดดีลแรก

## สถานะโค้ด ณ ตอนเขียน (อัปเดตล่าสุด)

แก้ตามตารางข้างบนแล้ว:

- `/api/tools/compare` เปิดให้ anon 10 ครั้ง/วันก่อนบังคับ login
- `lib/access-policy.ts` `FREE.compareDailyLimit` เป็นไม่จำกัด (ล็อกอินแล้ว), `FREE.salesQueryDailyLimit` เป็น 5
- `/market` เป็น public default snapshot แบบ quota-free; ไม่มี middleware page-view counter และไม่มี blur wall จากการเปิดหน้า
- interaction/analysis ของ market อยู่ที่ `/member/market`; server route เป็นจุดตรวจ session/tier/quota
- `/pricing` ไม่มี ฿399 tier แล้ว — เหลือ Pro ชั้นเดียว 3 ราคาตามระยะผูกมัด, Enterprise เป็นปุ่มติดต่อเดียว
- บทวิเคราะห์มีตาราง, admin authoring, public summary และ protected full-text route พร้อม `FREE.researchFullMonthlyLimit` = 2/เดือน
