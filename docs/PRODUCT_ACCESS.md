# TDR — ชั้นการเข้าถึงและราคา

ตกลงกับเจ้าของผลิตภัณฑ์แล้ว ใช้ไฟล์นี้เป็นแหล่งอ้างอิงเดียว ห้ามเดาจากโค้ดเดิม
โค้ดส่วนใหญ่ตรงกับตารางนี้แล้ว ยกเว้นส่วนที่ยังอยู่ใน PR แยกที่ยังไม่ merge
(ดู "สถานะโค้ด" ท้ายไฟล์)

### วิธีนับ

- **เทียบสเปก 4 ครั้ง** นับตอนกดปุ่มเทียบ ไม่ใช่ตอนเลือกรถ เก็บใน cookie ฝั่ง
  server (httpOnly) กันคนทั่วไปพอ ไม่ได้กันคนตั้งใจโกง ซึ่งไม่คุ้มจะกัน
- **market 1 ครั้ง/วัน ของ anon** นับด้วย cookie เหมือนกัน รีเซ็ตรายวันเวลาไทย
- **market 5 ครั้ง/วัน ของ FREE** นับเมื่อเปลี่ยนเงื่อนไขแล้วดึงข้อมูลจริง
  เปิดหน้าเฉยๆ หรือ refresh ไม่นับ
- **บทวิเคราะห์ 2/เดือน** นับตอนเปิดอ่านเต็มครั้งแรกของบทความนั้น
  อ่านซ้ำบทความเดิมไม่นับเพิ่ม

### หมายเหตุเรื่องการเบลอ

หน้า market ที่เบลอสำหรับ anon คือ **ข้อมูลจริงที่ถูกเบลอ** ไม่ใช่กราฟปลอม
คนละเรื่องกับ blurred placeholder ที่ถูกสั่งห้ามไว้ก่อนหน้า (นั่นคือรูปกราฟที่
ไม่มีข้อมูลอยู่จริงข้างหลัง)

## ราคา

| | ราคา | หมายเหตุ |
|---|---|---|
| Free | ฿0 | funnel |
| **Pro** (รายคน) — รายเดือน | **฿1,290/เดือน** | ไม่ผูกมัด เรียกเก็บทุกเดือน |
| **Pro** — ผูกมัด 3 เดือน | **฿990/เดือน** (รวม ฿2,970/รอบ) | เรียกเก็บเต็มก้อนล่วงหน้าทุก 3 เดือน |
| **Pro** — รายปี | **฿790/เดือน** (รวม ฿9,480/ปี) | เรียกเก็บเต็มก้อนล่วงหน้าทุกปี |
| Enterprise (TDR Enterprise package) | ปรับตามการใช้งานจริง | **ยังไม่ขึ้นเว็บ** ใช้ปุ่ม "ติดต่อเรา" เดียว ไม่มี Team แยก |

- **ยุบ ฿399 ทิ้ง** — ห่างจาก Pro เดิม (฿990) น้อยเกินกว่าจะช่วยตัดสินใจ Pro คือชั้นเสียเงินชั้นเดียว ปลดล็อกทุกอย่างเหมือนกันไม่ว่าจะสมัครแบบไหน ต่างกันแค่ระยะผูกมัด/ราคา
- Team ถูกยุบรวมเข้ากับ Enterprise เป็นบล็อกเดียว — "TDR Enterprise package" ปุ่มติดต่อเดียว ไม่แยกราคา/ที่นั่งบนเว็บ ปรับตามดีลจริงแต่ละองค์กร
- ยังไม่ติดราคา Enterprise บนเว็บ เพื่อไม่เสียอำนาจต่อรองก่อนปิดดีลแรก

## สถานะโค้ด ณ ตอนเขียน (อัปเดตล่าสุด)

แก้ตามตารางข้างบนแล้ว:

- `/api/tools/compare` เปิดให้ anon 4 ครั้งก่อนบังคับ login แล้ว
- `lib/access-policy.ts` `FREE.compareDailyLimit` เป็นไม่จำกัด (ล็อกอินแล้ว), `FREE.salesQueryDailyLimit` เป็น 5 แล้ว
- `/market` เปิดสาธารณะ 1 ครั้ง/วัน แล้วเบลอของจริง (ไม่ใช่กราฟปลอม) แล้ว
- `lib/public-market.ts` จำกัดช่วงเวลา/ย้อนหลัง/filter ตามชั้นแล้ว
- `/pricing` ไม่มี ฿399/฿990 แล้ว — เหลือ Pro ชั้นเดียว 3 ราคาตามระยะผูกมัด, Enterprise เป็นปุ่มติดต่อเดียว, มีลิงก์จาก nav และ footer แล้ว
