## Required operating invariants

- Original Website/Website Pro stays Layer 1–2. Dealership Toolkit stays a distinct Layer 3 product; no org-specific dealer interpretation or dealer CRM enters these pages.
- `portfolio.plan.json` remains non-executable. This manual Phase A document task grants no future task, merge, deploy, production write, external spend or autonomous-runner permission.

- The serving views are read contracts, never a write surface. Price Fetcher is the OEM price/spec collection pipeline, not an Ice package reader.
